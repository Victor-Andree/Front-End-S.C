# Integración futura

Aquí se implementará el cliente REST cuando exista el contrato de Spring Boot. No hay endpoints, peticiones ni credenciales configurados. Los mocks están en features/productos/data, features/ventas/data y features/dashboard/data. Los hooks de ventas y autenticación son los puntos de sustitución de la lógica de demostración. El backend deberá validar sesión, permisos, precios y existencias.
